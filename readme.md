# ffmpeg-tui --> myUpscaler first backbone



How to run
---------------

change directory to ffmpeg-tui folder that you clone
then

     ./build.sh
     
    ### you will see
        ####Compiling up60p_restore_beast_main.c with optimizations...
        ####Build complete. Binary 'up60p_restore_beast' created.
        ####execute the output, that will be your TUI

    ./up60p_restore_beast
    
    and your tui will start
    
    
    
What device I used it on?
---------------
I use a Macbook M series. for your information incase the program needs changes for your case
    
Troubleshooting
---------------
    absence of ffmpeg build. The ffmpeg build is needed to compile the executable.
